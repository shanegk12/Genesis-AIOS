System Components

Vocabulary

System
A group of parts working together to perform a function.
Subsystem
A smaller system inside a larger system.
Input
What goes into a system (energy, material, information).
Process
A series of steps used to create or improve something.
Output
What comes out of a system (motion, results, products).

System: Mousetrap Car

A mousetrap car converts stored elastic energy into forward motion. It demonstrates how every system has inputs, processes, and outputs working together through coordinated subsystems.
