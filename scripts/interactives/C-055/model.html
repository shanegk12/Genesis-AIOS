Power Grid Subsystem

Distributes electrical energy to all subsystems. Acts as the primary energy interface layer.

Control Hub (CPU)

Central processing unit. Receives sensor data, runs logic protocols, sends commands via interfaces.

Sensor Network

Distributed sensors (temp, motion, light). Collect real-time data; exemplify interoperability.

Actuator Array

Motors, valves, displays. Receive commands from Control Hub and produce physical outputs.

Communication Bus

Shared protocol layer (like I²C or CAN bus) allowing all subsystems to exchange information.
