Mousetrap Build · Lesson: Arduino Station and Test

Genesis K-12
Academy

Components

Arduino Uno
Microcontroller board that runs code and reads sensor inputs in real time.
Breadboard
Prototyping board for connecting sensors and components without soldering.
IR Distance Sensor
Detects distance traveled by the mousetrap car using infrared light reflection.
USB Data Cable
Transfers power and logged data between the Arduino and a laptop/PC.
Jumper Wires
Flexible wires that connect Arduino pins to breadboard components.
Station Base
Flat platform that organizes all components for stable data collection.

View Controls

Drag to rotate · Click components to highlight · Use buttons to explore
