# Daily plan template

Copy to `context/shane/daily-plans/YYYY-MM-DD.md` and fill in. The SessionStart
hook (`scripts/aios_hooks.py`) checks for today's file and flags it if missing.

Keep it short. A plan that takes ten minutes to write is a plan that lapses.

---

# YYYY-MM-DD

## The one thing
<If only one item gets done today, this is it. One line.>

## Also today
- <second priority>
- <third priority>

## Waiting on
- <person or system> : <what, and since when>

## Carried from yesterday
- <anything that did not get done, and whether it still matters>

## Notes
<Anything worth remembering that is not a task. Decisions made, things learned,
things that surprised you. Real decisions belong in `decisions/log.md` instead.>
